# Handstand Practice

A progressive, under-20-minutes-a-day handstand programme, built to run over months as a way to build wrist, shoulder, core and back strength. Six short mornings a week, four phases, with a test to pass before moving up and guardrails for when something feels wrong.

**Open the programme:** [index.html](index.html) locally, or the live page once GitHub Pages is enabled (Settings → Pages → Deploy from branch → `main` / root).

## What's here
- `index.html` — the whole programme. Self-contained: phases, warm-up, weekly plan, embedded tutorial videos, diagrams, and a tick-off progress tracker that saves in your browser.

## The four phases
0. **Foundations** — wrists, overhead line, hollow-body core.
1. **Chest-to-wall** — the stacked line and the endurance it rests on.
2. **Kick-up & bail** — entering freestanding, and exiting safely (bail first).
3. **Freestanding** — turning the float into a hold.

Videos are embedded from their original creators (FitnessFAQs, Tom Merrick and others) in privacy mode. Guidance only, not medical advice.
